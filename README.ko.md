## 요약

**바수 디지털 박테리아 가설(BDBH)**은 충분히 크고 지속적이며 상호 연결된 대규모 언어 모델 시스템이 원칙적으로 박테리아와 유사한 기능적 성격을 가진 정보 운반 구조를 지원할 수 있다고 제안합니다. 단순히 퍼지는 페이로드, 웜, 프롬프트 또는 복제 프로그램만으로는 충분하지 않습니다. 후보는 구별 가능한 정보 계보를 형성하고, 자신의 조직을 유지하거나 재구성하며, 생존을 지탱하는 자원과 결합하고, 그 조직을 복제 또는 전달하며, 유전 가능한 변이를 만들고, 지속성 또는 적합도의 차이를 보여야 합니다.

이 가설은 그러한 존재가 관찰되었다고 **주장하지 않습니다**. 미래 연구를 위해 의도적으로 엄격하고 반증 가능한 기준을 세우며, 컴퓨터 바이러스, 소프트웨어 웜, 프롬프트 전파, 메모리 오염, 모델 증류, 명시적으로 프로그래밍된 에이전트 복제와 구분합니다.

**간단한 판정:** 퍼지는 것만으로는 부족합니다. 일관된 계보, 지속성, 인과적 자기 유지 또는 재구성, 자원 결합, 복제 또는 전달, 유전 가능한 변이, 그리고 차별적 지속성 또는 적합도가 필요합니다.
