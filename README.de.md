## Zusammenfassung

Die **Basu Digital Bacterium Hypothesis (BDBH)** schlägt vor, dass hinreichend große, dauerhafte und vernetzte Systeme großer Sprachmodelle grundsätzlich informationstragende Strukturen mit bakterienähnlichem Funktionsprofil tragen könnten. Ein sich lediglich verbreitender Payload, Wurm, Prompt oder ein kopiertes Programm genügt nicht. Ein Kandidat müsste eine unterscheidbare informationelle Abstammungslinie bilden, seine Organisation erhalten oder rekonstruieren, an tragende Ressourcen gekoppelt sein, diese Organisation reproduzieren oder übertragen, vererbbar variieren und unterschiedliche Persistenz oder Fitness zeigen.

Die Hypothese behauptet **nicht**, dass ein solches Gebilde beobachtet wurde. Sie formuliert eine bewusst anspruchsvolle und falsifizierbare Schwelle für künftige Forschung und grenzt das Konzept von Computerviren, Softwarewürmern, Prompt-Verbreitung, Memory Poisoning, Modelldestillation und ausdrücklich programmierter Agentenreplikation ab.

**Einfacher Test:** Verbreitung allein reicht nicht. Erforderlich wären kohärente Abstammung, Persistenz, kausale Selbsterhaltung oder Rekonstruktion, Ressourcenkopplung, Reproduktion oder Übertragung, vererbbare Variation und unterschiedliche Persistenz oder Fitness.

## Forschungsstatus

**Es wird nicht behauptet, dass ein digitales Bakterium existiert oder beobachtet wurde. Die Arbeit formuliert eine falsifizierbare Hypothese und Terminologie für zukünftige Forschung.**
