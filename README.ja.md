## 概要

**バス・デジタル細菌仮説（BDBH）**は、十分に大規模で持続的かつ相互接続された大規模言語モデル・システムが、原理的には細菌に似た機能的性質を持つ情報担体構造を支え得ると提案します。単に拡散するペイロード、ワーム、プロンプト、または複製プログラムだけでは該当しません。候補は、識別可能な情報系統を形成し、自らの組織を維持または再構築し、存続を支える資源と結合し、その組織を複製または伝達し、遺伝可能な変異を生じ、持続性または適応度の差を示す必要があります。

この仮説は、そのような存在が観察されたとは**主張しません**。将来の研究に対して意図的に厳格で反証可能な基準を設定し、コンピューターウイルス、ソフトウェアワーム、プロンプト伝播、メモリ汚染、モデル蒸留、明示的にプログラムされたエージェント複製と区別します。

**簡単な判定：**拡散するだけでは不十分です。系統の一貫性、持続性、因果的な自己維持または再構築、資源との結合、複製または伝達、遺伝可能な変異、そして持続性または適応度の差が必要です。
