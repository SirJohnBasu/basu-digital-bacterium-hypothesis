## 摘要

**巴苏数字细菌假说（BDBH）**提出：足够庞大、持久且互联的大语言模型系统，原则上可能支持具有类似细菌功能特征的信息承载结构。仅仅传播的载荷、蠕虫、提示词或复制程序并不符合条件。候选对象必须形成可区分的信息谱系，维持或重建自身组织，与维持其存在的资源发生耦合，复制或传递该组织，产生可遗传变异，并表现出不同的持续性或适应度。

本假说**并不声称**已经观察到此类实体。它为未来研究设定了一个有意严格且可证伪的门槛，并将该概念与计算机病毒、软件蠕虫、提示传播、记忆投毒、模型蒸馏以及明确编程的智能体复制区分开来。

**通俗检验：**仅会传播还不够；还必须证明谱系连贯性、持续存在、因果性的自我维持或重建、资源耦合、复制或传递、可遗传变异，以及不同的持续性或适应度。
